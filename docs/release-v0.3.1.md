**Beta.** Ikemen NX v0.3.1 adds **automatic updates**. Install this version once by hand; from then on the engine and the apps update themselves from GitHub.

### Included

| | Version |
|---|---|
| Engine (`ikemen.nro`) | 0.3.1 |
| Ikemen NX Config | 1.3.0 |
| Ikemen NX Browser | 1.1.0 |

### What's new

- **Engine:** checks for a new version at start (at most once a day) and offers to update. Each game keeps its own icon and name.
- **Ikemen NX Config:**
  - checks at start, or from *Buscar actualizaciones*, and updates itself, the browser and every game's engine in one go;
  - includes import, *Crear juego nuevo*, and the screenpack and lifebar selectors.
- **Ikemen NX Browser:** checks for its own updates at start.
- Updates need internet and are skipped silently when offline. Press **X** on the prompt to turn the automatic check off.

### Install

1. Extract `ikemen-nx-v0.3.1-sd.zip` to the root of the SD card. If you already have games in `switch/ikemen`, copy only the three `.nro` files instead.
2. If you extracted on Windows, clear the archive bit (Hekate → *Fix Archive Bit*).
3. Open the homebrew menu in title mode (hold R).
