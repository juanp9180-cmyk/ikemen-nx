**Beta.** Ikemen NX v0.3.2 moves the engine to **Go 1.27.4** (security and bug fixes from Go 1.27.3 and 1.27.4). No changes to the games or the apps.

### Included

| | Version |
|---|---|
| Engine (`ikemen.nro`) | 0.3.2 |
| Ikemen NX Config | 1.3.0 (unchanged) |
| Ikemen NX Browser | 1.1.0 (unchanged) |

### Update

- **From v0.3.1:** the engine offers this update by itself the next time a game starts (it checks at most once a day). Or update every game at once from Ikemen NX Config → *Buscar actualizaciones*.
- **New install:** extract `ikemen-nx-v0.3.2-sd.zip` to the root of the SD card, clear the archive bit if you extracted on Windows (Hekate → *Fix Archive Bit*), and open the homebrew menu in title mode (hold R).
